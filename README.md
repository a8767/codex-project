# CODEX projects

This public repository contains two CODEX projects in separate directories:

- `售后数据计算/`
- `淘宝批量发布视频自动化/`

Raw after-sales input data, generated calculation results, videos, test captures, temporary files, local databases, and dependency/build caches are excluded. Each project directory contains its own `.gitignore` to keep those files out of future commits.
