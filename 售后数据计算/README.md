# 售后月度数据计算

## 输入与输出

- 输入目录：`原始数据`
- 模板目录：`数据表模板`
- 输出目录：`数据计算`

运行 `generate_monthly_reports.py` 会按模板生成总数据、小组、大组、工厂、车型、配件和店铺共 7 份月度报表。影刀流程请调用 `影刀_售后月度数据计算.py` 的 `generate_report`。

## 原始数据要求

`补发数据.xlsx` 用于统计补发次数，按 `登记时间` 筛选月份。新增表缺少售后组时，程序按 `店铺规范.xlsx` 中的“实际负责”（无值时“售后组”）归属；工厂优先使用“工厂匹配”；车型优先按“英文编码整合”映射，无法匹配的记录归入配件。

`补偿数据.xlsx` 用于统计补偿金额。仅“是否不参与计算判断”为“否”的记录计入补偿金额；它不再影响补发次数。

## 命令行运行

```powershell
python generate_monthly_reports.py --month 2026-09 --created-date 20260911
```

生成文件保存在 `数据计算`，文件名为 `报表名称_创建日期.xlsx`。运行前请确认 7 份输入表均在对应目录，且月份与源表登记日期一致。

## 核验口径

- 总表补发次数应等于当月 `补发数据.xlsx` 的有效记录数。
- 总表补偿金额应等于当月 `补偿数据.xlsx` 中参与计算记录的“补偿金额”合计。
- 小组、店铺、工厂、车型和配件报表的补发/补偿汇总应可回溯至同一来源。
