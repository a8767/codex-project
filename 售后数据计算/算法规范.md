# 售后月度数据计算算法规范

## 1. 适用范围与通用规则

本规范适用于 `generate_monthly_reports.py` 和 `影刀_售后月度数据计算.py` 生成的总数据、小组、大组、工厂、车型、配件和店铺 7 份月度输出表。

- **统计月份**：按运行参数 `YYYY-MM`。退货、补发、补偿均按各原始表的“登记时间”筛选；“09月08日”这类无年份日期使用统计月份的年份。
- **补发次数**：当月 `补发数据.xlsx` 每条记录计 1 次，不以补偿记录代替。
- **补偿金额**：当月 `补偿数据.xlsx` 中“是否不参与计算判断”为“否”的“补偿金额”之和。
- **签收退货单量**：当月 `退货数据.xlsx` 中“退货退款原因”不含“截回”“拦截”“拒收”的记录数；不再要求“实际退回仓库”有值。
- **比率**：`分子 ÷ 分母`；分母为 0 时输出 `0`。输出单元格为数值，显示格式为百分比。
- **数值取整**：所有报表先按原始数值字段完成归集，再将营业额、销售额、补偿金额、订单量、退货量和补发次数等金额/数量指标按“四舍五入”取整至 0 位小数；不得汇总源表中已逐行取整或已汇总的辅助列。比率字段不参与数值取整。
- **归属规则**：补发数据缺少售后组时，使用 `店铺规范.xlsx` 的“实际负责”，仍为空再取“售后组”；工厂优先取“工厂匹配”，否则“工厂”，均为空归入“未匹配工厂”。车型优先取车型字段或按英文编码映射，无法映射归入“未匹配车型或配件”。

## 2. 总数据计算

| 表头 | 算法或来源 |
| --- | --- |
| 已确认登记表无误 | 固定值“已确认” |
| 营业额 | `店铺规范.xlsx` 全部店铺“当日真实营业额”合计 |
| 订单量 | `店铺规范.xlsx` 全部店铺“车子销量”合计 |
| 退货单量 | 当月退货记录数 |
| 补发次数、订单补发 | 当月补发记录数 |
| 补偿金额 | 当月参与计算补偿记录的“补偿金额”合计 |
| 退货率 | 退货单量 ÷ 订单量 |
| 补偿率 | 补偿金额 ÷ 营业额 |
| 补发率 | 补发次数 ÷ 订单量 |
| 万里牛补发 | 当前固定为 0 |
| 数据日期 | 统计月份去掉连字符，例如 `202609` |

## 3. 小组数据计算与大组数据计算

两张表使用相同指标。小组按“售后组”归集；大组由小组名称转换，`售后A1组/售后A2组` 归“售后A组”，B、C 组同理，其他名称保持原值。

| 表头 | 算法或来源 |
| --- | --- |
| 售后组 | 小组名称，或大组名称 |
| 大组 | 由售后组转换的所属大组（仅小组表） |
| 营业额、订单量 | 归属店铺的“当日真实营业额”“车子销量”合计 |
| 配件店铺订单量 | 仅“只销配件店铺”的“配件销量”合计 |
| 退货单量、店铺退货 | 当月归属退货记录数 |
| 签收退货单量 | 归属退货记录中“退货退款原因”不含“截回”“拦截”“拒收”的记录数 |
| 补发次数 | 当月归属补发记录数 |
| 配件店铺补发次数 | 归属补发中店铺为“只销配件店铺”的记录数 |
| 补偿金额 | 当月归属参与计算补偿金额合计 |
| 退货率、签收退货率、补偿率、补发率、配件店铺补发率 | 分别以退货、签收退货、补偿、补发、配件店铺补发为分子；分母依次为订单量、订单量、营业额、订单量、配件店铺订单量 |
| 售后率 | `(退货单量 + 补发次数) ÷ 订单量` |
| 日期、数据月份 | 统计月份 `YYYY-MM` |
| 月份、月份判断、判断月份 | 统计月份去掉连字符 |

## 4. 工厂数据计算

| 表头 | 算法或来源 |
| --- | --- |
| 工厂名称、工厂 | 工厂名称 |
| 营业额、订单量 | `工厂数据.xlsx` 的原始“营业额”“订单量”；原始字段缺失时才回退到对应汇总列 |
| 退货单量 | 当月退货记录按“工厂”归集的记录数 |
| 补发次数、补发次数 （除万里牛） | 当月补发记录按“工厂匹配”优先、再“工厂”归集的记录数 |
| 补偿金额 | 当月参与计算补偿记录按“工厂”归集的金额合计 |
| 退货率、补偿率、补发率 | 分别为退货单量 ÷ 订单量、补偿金额 ÷ 营业额、补发次数 ÷ 订单量 |
| 日期、月份 | 统计月份 `YYYY-MM`、去连字符月份 |

## 5. 车型数据计算

| 表头 | 算法或来源 |
| --- | --- |
| 车型、型号 | 车型名称 |
| 营业额、销售额 | 永久、菲利普、大众日销表按车型汇总原始“销售额”字段，汇总完成后再按数值取整规则输出；不使用永久日销中已逐行取整的“销售额（汇总）” |
| 订单量 | 永久、菲利普、大众日销表按车型的销量 |
| 退货单量、退货量 | 当月退货按品牌编码映射到车型后的记录数 |
| 补发次数、补发次数量 | 当月补发按车型或英文编码映射到车型后的记录数 |
| 补偿金额、补偿金额量 | 当月参与计算补偿按车型或英文编码映射后的金额合计 |
| 退货率、补偿率、补发率 | 退货量 ÷ 订单量、补偿金额 ÷ 销售额、补发次数 ÷ 订单量 |
| 日期、月份 | 统计月份 `YYYY-MM` |

## 6. 配件数据计算

| 表头 | 算法或来源 |
| --- | --- |
| 配件型号名称 | `配件日销.xlsx` 的“标题”；无车型映射的售后记录按配件英文编码、车型、中文编码依次归属 |
| 销售额、营业额 | 配件日销按标题汇总的“销售额” |
| 配件订单量、订单量 | 配件日销按标题汇总的“销量” |
| 退货量、退货单量 | 当前输出为 0，退货未按配件编码归集 |
| 补发次数量、补发次数 | 当月归属配件的补发记录数 |
| 补偿金额量、补偿金额 | 当月归属配件的参与计算补偿金额合计 |
| 退货率、补偿率、补发率 | 退货量 ÷ 配件订单量、补偿金额 ÷ 销售额、补发次数 ÷ 配件订单量 |
| 日期、月份 | 统计月份 `YYYY-MM` |

## 7. 店铺数据计算

| 表头 | 算法或来源 |
| --- | --- |
| 店铺名称、售后组、大组、运营组、配件组、平台、只销配件店铺 | `店铺规范.xlsx` 对应字段；大组按小组转换规则生成 |
| 营业额、订单量 | 店铺规范的“当日真实营业额”“车子销量” |
| 配件店铺订单量 | 只销配件店铺的“配件销量”，其他店铺为 0 |
| 退货单量 | 当月按“店铺”归属的退货记录数 |
| 签收退货单量 | 上述退货中“退货退款原因”不含“截回”“拦截”“拒收”的记录数 |
| 补发次数 | 当月按店铺归属的补发记录数；店铺名“自行车/车”字样差异仅在唯一匹配时自动修正 |
| 配件店铺补发次数 | 只销配件店铺的补发记录数，其他店铺为 0 |
| 补偿金额 | 当月按店铺归属的参与计算补偿金额合计 |
| 退货率、签收退货率、补偿率、补发率、配件店铺补发率 | 分子分别为对应指标；分母为订单量、订单量、营业额、订单量、配件店铺订单量 |
| 日期 | 统计月份 `YYYY-MM` |
| 判断月份 | 统计月份去掉连字符 |
| 售后率 | `(退货单量 + 补发次数) ÷ 订单量` |

## 8. 核对规则

核对时，先验证总表控制数，再验证小组、大组、工厂、店铺汇总与总表一致；车型与配件的合计也应与总表的补发次数和补偿金额一致。出现“未匹配工厂”或“未匹配车型或配件”时，记录仍计入总表，需补全源数据字段后再重新计算。
